About the Game

Neo-Vanguard: Prime is a revolutionary first-person tactical shooter set in the hyper-connected megacity of Zenith. Players assume the role of 'Vanguards', elite mercenaries equipped with cutting-edge neural interfaces and gravity-defying traversal gear. Experience seamless urban combat where every wall is a potential flanking route and every light source is a tactical advantage.
